# Sprint 20 — manual ownership transfer

Keep the existing desktop workspace and Quiet Heritage components. No mobile
management, new public directory or Penpot synchronization.

Owners choose an eligible current admin from the private staff roster. Explain
that acceptance gives that admin owner powers, makes the old owner a regular
member and does not remove either person's registrations or event-chat access.
Show a seven-day deadline in Manila time and require an explicit nomination
confirmation. One offer may be pending; revoke it before choosing someone else.

The named admin sees their own offer and can accept or decline; other admins
cannot act. The owner may revoke before acceptance. Each confirmation captures
the particular offer/version, starts on Cancel, supports Escape and restores
focus. A clock/role conflict refreshes the record and requires fresh review; never
silently redirect a click to another nominee or offer. An uncertain retry keeps
the submitted client key/action/version, not a new request with edited choices.

After acceptance refresh both server role/grants and workspace data. The former
owner's management controls disappear, while member participation remains. In-app
notices route using the current role, not the original creator field. No incoming
ownership management requests run on mobile. Account/context changes abort old
requests and discard private state. English and Filipino copy share the existing
localization system; no new motion or image system.

Automated API/component checks are not live browser or participant testing.
Record actual evidence separately and retain Sprint 18's pending browser and
dependency-security build gates until explicitly resolved.
